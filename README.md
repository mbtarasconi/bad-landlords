# Bad Landlords

Monopoly sem freio pra jogar com os amigos: casas da sua cidade, cartas com os podres do grupo, tribunal, maldições e falência com estilo.

- `index.html`: o jogo inteiro (página única).
- `server.js`: servidor Node sem dependências. Entrega a página e faz as salas online (Server-Sent Events).
- Rodar local: `npm start` e abrir http://localhost:8080
